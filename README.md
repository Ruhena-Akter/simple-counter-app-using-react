# Simple Counter App

## Project Description

A simple and responsive Counter App built with React JS. This project demonstrates the use of the useState hook and event handling with onClick.

## Features

* Starts counting from 0.
* Increment (+): Increases the count by 1.
* Decrement (-): Decreases the count by 1.
* Reset: Resets the count to 0.
* Clean and responsive user interface.
* Smooth animations and interactive buttons.

## Technologies Used

* React JS
* JavaScript
* HTML
* CSS
* Vite

## How to Run the Project

### 1. Clone the Repository

git clone YOUR_GITHUB_REPOSITORY_URL

### 2. Navigate to the Project Folder

cd simple-counter-app

### 3. Install Dependencies

npm install

### 4. Start the Development Server

npm run dev

### 5. Open the Application

Open the local URL displayed in your terminal, usually http://localhost:5173/
